# Baseball Blast: Umpire Challenge

A browser-based baseball game where the player works as the home plate umpire and calls each pitch a ball or strike.

## How to play

1. Choose Easy, Normal, or Hard mode.
2. Watch the pitch cross home plate.
3. Call **Strike** or **Ball**.
4. Build an accuracy streak and try to reach the top of the local leaderboard.

Keyboard controls:

- `S`: Strike
- `B`: Ball
- `Space`: Start/next pitch

## Features

- Animated fastballs, sliders, curveballs, cutters, changeups, and two-seam fastballs
- Three difficulty levels with different pitch speeds and edge-call frequency
- Ball/strike count, outs, innings, scoring, accuracy, and streak tracking
- Pitch-by-pitch review and visual strike-zone reveal
- Sound effects and mobile-friendly controls
- Local high-score leaderboard saved in the browser

## Run locally

Open `index.html` in a modern browser. No build step or server is required.
